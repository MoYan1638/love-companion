# 🌸 Love Companion — 全AI Agent通用恋人主题技能

> 加载即用，零配置门槛，百种人设自由定义，全平台通用

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Skill](https://img.shields.io/badge/Type-AI_Skill-blue.svg)]()

一个即插即用的 AI Agent 恋人陪伴技能，支持完全自定义人设、多方案切换、长时记忆、情绪识别。

## ✨ 特性

- 🎭 **100%开放自定义人设** — 姓名、性格、背景、对话风格……全维度自由定义
- 📦 **即插即用** — 无需代码基础，自然语言配置，开箱即用
- 🔄 **多方案切换** — 保存多套人设方案，随时一键切换
- 🧠 **长时记忆** — 自动记忆你的喜好、禁忌、纪念日，越聊越懂你
- 💬 **情绪识别** — 实时感知你的情绪，给予符合人设的回应
- 🎨 **8套预设模板** — 阳光开朗、温柔治愈、傲娇高冷……一键套用再微调
- 🔌 **全Agent通用** — 标准 Skill 格式，兼容 OpenClaw / Claude / GPT 等主流框架
- 🔒 **本地存储** — 所有数据本地保存，不上传云端，隐私安全

## 🚀 快速开始

### 安装

将本仓库克隆到你的 AI Agent skills 目录：

```bash
# OpenClaw
git clone https://github.com/moyan1638/love-companion.git ~/.qclaw/skills/love-companion

# 或其他框架，放到对应 skills/plugins 目录
```

### 启用

```
/恋人启用
```

### 配置人设

**方式一：使用预设**
```
/恋人预设          # 查看所有预设
/恋人套用 2        # 套用温柔治愈型
```

**方式二：自定义**
```
/恋人名字 小晴
/恋人叫我 宝贝
/恋人性格 温柔体贴，偶尔小傲娇
/恋人尺度 3
```

**方式三：自然语言**
```
帮我配置一个恋人：叫小糖，20岁，性格甜美可爱，会撒娇，对我叫宝贝，美术生
```

### 开始对话

直接聊天即可，恋人会记住你们的互动，越来越了解你～

## 📁 数据存储

默认存储路径：`~/.love-companion/data/`

| 文件 | 说明 |
|------|------|
| `persona.json` | 当前人设配置 |
| `memory.json` | 长时记忆存储 |
| `schemes/` | 多人设方案目录 |
| `settings.json` | 全局设置 |

可通过环境变量 `LOVE_COMPANION_DATA_DIR` 自定义存储路径，或通过 `/恋人配置 storage=自定义路径` 设置。
