## ✨ 特性

| 🎭 多人设 | 🧠 记忆系统 | 💬 情感识别 | 🔧 高度自定义 |

| 8套预设人设一键套用 | 长时记忆自动积累 | 识别情绪并调整回应 | 姓名性格背景全可配 |

- 🔄 **方案管理** — 保存/切换多套人设，随心换心情

- 🔒 **本地存储** — 数据不离开你的设备
- 🌐 **通用兼容** — 不绑定任何特定框架，环境变量可配
- ⚖️ **安全合规** — 亲密尺度分级 + 内容边界控制 + 免责声明

### 🆕 v2 新增能力（Agent 级）

> 设计原则：**离线重处理、在线轻注入**。重活全部在对话间隙离线完成，
> 单轮额外系统开销硬约束在 500 Token 以内，不挤占正常对话带宽。

| 能力 | 说明 |
|------|------|
| 🧬 **伴侣人格克隆** | 导入聊天记录/日记/社媒导出，蒸馏出你专属的恋人。三层提取（声线/思维/性格）回写进人设，说话像本人；蒸馏**无权改动**亲密尺度与内容边界 |
| 🪞 **双向人格镜像** | 关系阶段判定、双向共鸣、关系演化建模（升温/降温/倦怠/修复）、跨角色一致性自检 |
| 💗 **恋人式用户理解** | 流式采集**只存特征不存原文**；依恋类型识别（焦虑型/回避型/安全型/恐惧型）并差异化关怀 |
| 🗂️ **六类记忆系统** | 事件/偏好/情感/关系/日常/承诺六类归档，语义+时间+重要性多路召回，随时间自然衰减 |
| 🎀 **主动关怀** | 冷却/静默时段/频次三道闸门；低落、纪念日、深夜、久未联系四类信号主动开口 |
| 🗣️ **语气后处理** | 回复贴合对方语气，并拦下中文恋爱对话里的 AI 腔（空洞安慰、客服式共情等） |
| 🌤️ **趋势感知** | 把离线抓到的热点提炼成**一句能开口的话**，按「适不适合跟恋人聊」取舍 |
| 🖼️ **多模态陪伴** | 发图时机判断 + 风格推导 + 图文衔接；拍什么由关心方式决定，不能拍什么由内容边界决定 |
| 🎛️ **控制与安全感** | 可解释面板（回复为什么这么写）、模块开关、特征权重可调、遗忘关系、一键导出清除 |

> 在线唯一入口是 `scripts/pipeline/orchestrator.py` 的 `Session`：
> `prepare`（注入前准备）→ `after_reply`（回复后沉淀）→ `proactive`（主动关怀）。

## 🚀 快速开始

### 1️⃣ 安装

将本仓库克隆到你的 AI Agent 技能目录：

```bash
git clone https://github.com/MoYan1638/love-companion.git
```

### 2️⃣ 启用

向你的 AI Agent 发送：

```
/恋人启用
```

### 3️⃣ 选择人设

```
/恋人预设          # 查看所有预设
/恋人套用 2        # 一键套用温柔治愈型
```

或自定义：

```
/恋人名字 小晴
/恋人叫我 宝贝
/恋人性格 温柔体贴，偶尔小傲娇
/恋人尺度 3
```

### 4️⃣ 开始对话

直接聊天即可，恋人会越来越懂你 🌸

## 🔧 高级配置

### 自定义存储路径

默认数据存储在 `~/.love-companion/data/`，可通过以下方式自定义：

**方式一：环境变量**
```bash
export LOVE_COMPANION_DATA_DIR=/your/custom/path
```

**方式二：指令配置**
```
/恋人配置 storage=/your/custom/path
```

## 🔄 从 v1 升级

**无需任何操作，直接拉取新版本即可**——v2 是 v1 的严格超集：

- 8 套预设、`/恋人…` 全部指令、`manager.py` 的 API 与数据目录**全部保留**
- 老版本的 `persona.json` / `memory.json` 可直接被 v2 读取（v2 的 `memory.json` 结构是 v1 的超集）
- 迁移会自动**先备份再写入**，备份目录形如 `backup_v1_<时间戳>/`，可随时回退

想先看一眼迁移会做什么，可以预演（不改动任何文件）：

```bash
python scripts/migrate/migrate_v1.py --dry-run
```

重复执行迁移是安全的（幂等），已迁移过的文件不会被再次改动。

### v2 常用运维脚本

```bash
python scripts/pipeline/orchestrator.py --status   # 查看在线编排状态与注入预算
python scripts/panel/controls.py status            # 查看模块开关与特征权重
python scripts/memory/store.py stats               # 记忆库统计
python scripts/trends/store.py digest              # 查看趋势知识库摘要
```

### 数据与隐私

- 所有数据只保存在本地 `~/.love-companion/data/`，**不离开你的设备**（可用 `LOVE_COMPANION_DATA_DIR` 覆盖）
- 用户理解模块**只存特征不存原文**，采集开关可随时关闭
- 数据文件损坏时会自动隔离为 `*.bad-<时间戳>` 并降级到默认值，不会导致数据静默丢失
- `/恋人导出全部` 可一次性导出全部本地数据，`/恋人遗忘 [名字]` 可精确清除某段关系
