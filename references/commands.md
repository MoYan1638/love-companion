# 完整指令参考手册

> 全AI Agent通用标准化指令，即插即用
>
> 覆盖 v1 基础指令（一～七章）与 v2 能力指令（第八章）。v1 指令全部向后兼容，老用法不用改。

---

## ⚠️ 免责声明

- 本技能为 **AI 角色扮演工具**，所有对话均为 AI 生成，**不代表真实人际关系**。
- **仅限已满 18 周岁**。未完成「已满18周岁」确认前，`/恋人启用` 只返回合规提示，不加载任何人设与记忆。
- 请勿将 AI 陪伴**替代真实社交**或**专业心理辅导**。

---

## 指令格式说明

- 所有指令以 `/恋人` 开头
- 方括号 `[]` 表示必填参数
- 圆括号 `()` 表示可选参数
- 指令大小写不敏感

## 一、核心开关指令

### /恋人启用

**功能**：激活恋人Skill，进入情感对话模式

**响应**：
- 加载当前人设配置
- 激活记忆系统
- 以恋人身份开始对话

**示例**：
```
/恋人启用
```

---

### /恋人关闭

**功能**：关闭恋人模式，恢复普通AI对话

**响应**：
- 退出恋人角色
- 保留所有配置和记忆
- 可随时再次启用

**示例**：
```
/恋人关闭
```

---

## 二、人设配置指令

### /恋人配置

**功能**：查看或修改当前人设配置

**用法**：
- 不带参数：显示当前完整配置
- 带参数：修改指定配置项

**语法**：
```
/恋人配置                          # 查看当前配置
/恋人配置 [JSON内容]               # 直接传入JSON配置
/恋人配置 [维度]=[值]              # 修改单个维度
/恋人配置 [维度].[子维度]=[值]     # 修改嵌套维度
```

**示例**：
```
/恋人配置
/恋人配置 姓名=小雨
/恋人配置 性格.核心特质 = ["温柔", "体贴"]
/恋人配置 {"姓名":"小晴","年龄":22}
```

---

### /恋人预设

**功能**：列出所有可用的预设人设模板

**响应**：显示预设编号和名称列表

**示例**：
```
/恋人预设
```

输出示例：
```
【预设人设列表】
1. 阳光开朗型 - 活泼正能量，像小太阳
2. 温柔治愈型 - 贴心关怀，情感细腻
3. 傲娇高冷型 - 外冷内热，欲拒还迎
...
```

---

### /恋人套用 [序号]

**功能**：一键套用预设人设模板

**参数**：
- `序号`：预设编号（1-8）

**示例**：
```
/恋人套用 1      # 套用阳光开朗型
/恋人套用 3      # 套用傲娇高冷型
```

**注意**：套用后会覆盖当前配置，建议先保存当前方案

---

### /恋人重置

**功能**：重置为默认空白人设

**响应**：清空所有自定义配置，恢复初始状态

**示例**：
```
/恋人重置
```

## 四、记忆管理指令

### /恋人记忆 [内容]

**功能**：手动添加记忆内容到长时记忆

**参数**：
- `内容`：要记忆的信息

**示例**：
```
/恋人记忆 我最讨厌被敷衍
/恋人记忆 我的生日是5月20日
/恋人记忆 我最近在准备考研，压力很大
```

---

### /查看记忆

**功能**：查看当前所有长时记忆

**响应**：显示记忆条目列表，包含编号、内容、记录时间

**示例**：
```
/查看记忆
```

输出示例：
```
【长时记忆】
1. 用户生日：5月20日（记录于2024-04-15）
2. 用户讨厌被敷衍（记录于2024-04-20）
3. 用户正在备考研究生（记录于2024-05-01）
```

---

### /删除记忆 [关键词]

**功能**：删除包含指定关键词的记忆条目

**参数**：
- `关键词`：用于匹配的记忆关键词

**示例**：
```
/删除记忆 生日
/删除记忆 考研
```

---

### /恋人清空记忆

**功能**：清空所有对话记忆与长时记忆

**注意**：此操作不可恢复

**示例**：
```
/恋人清空记忆
```

## 八、v2 能力指令

这一组不是命令行参数，而是**说给 Agent 听的话**：Agent 解析指令后调对应模块（`scripts/persona/`、`scripts/panel/`、`scripts/pipeline/` 等），用户不需要记路径。重活都在对话间隙离线跑，不占当前这轮。

| 指令 | 干什么 | 前置 / 边界 |
|---|---|---|
| `/恋人蒸馏 [名字]` | 从聊天记录/日记素材蒸馏伴侣人格（声线·思维·性格三层） | 素材由用户提供；蒸馏结果先落人格库，不直接改人设 |
| `/恋人落地人设 [名字]` | 把蒸馏结果写回 `persona.json` | 人设真相源只有一个；覆盖前提示旧值 |
| `/恋人人格` | 列出人格库（含版本号） | - |
| `/恋人纠偏 [不该这样说] → [应该这样说]` | 写入纠偏层，下一轮立即生效 | 只改说话方式，不动亲密尺度与内容边界 |
| `/恋人回滚 [名字] [版本号]` | 人格回滚到历史版本 | - |
| `/恋人关系` | 查看关系阶段、亲密度、趋势与共鸣话题 | 需要已有对话积累，冷启动时如实说没有 |
| `/恋人解释` | 可解释面板：上一轮为什么这么说，依据是哪条记忆/哪个人格字段 | 只解释依据，不给「心理分析」 |
| `/恋人修正 [特征路径] [0-1]` | 修正对用户的理解权重，0 = 别用这条判断 | 特征路径见 `/恋人状态` 输出 |
| `/恋人开关 [模块] [开/关]` | 模块开关：记忆系统/人格克隆/用户理解/语气后处理/主动关怀/趋势感知/多模态/可解释面板/军师模式 | 关掉即真不加载，不是降权 |
| `/恋人军师` | 进入军师模式（顾问口吻，**不读人设、不读恋人记忆**） | 默认关闭，需先用 `/恋人开关 军师模式 开`；说「陪我聊会儿」退出 |
| `/恋人关怀` | 手动触发一次主动关怀判定 | 仍受冷却/静默时段/频次三道闸门 |
| `/恋人遗忘 [名字]` | 遗忘某段关系：人格 + 关系演化 + 该关系的记忆一并清除 | 不可撤销，执行前二次确认 |
| `/恋人导出全部` | 导出全部本地数据（设置/记忆/画像/趋势） | 导出物含对话特征，别随手发人 |

**三条硬边界**（v2 指令也不能越过）：

1. **合规闸门优先**：未确认已满 18 周岁时，上述指令一律不注入人设与记忆，只回合规提示。
2. **军师模式与人设互斥**：同一轮只能在一个模式里，切换时用一句话说明，不默默换。
3. **数据主权在你**：`/恋人遗忘`、`/恋人导出全部`、模块开关都是即时生效的，不需要重装。
